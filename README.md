# free_fly (release mirror)

Installable releases of the **free_fly** mod for [gen1recomp](https://github.com/bryanthaboi/gen1recomp).

Grab the newest `.zip` from [Releases](https://github.com/shanehudson-gen1recomp-mods/free_fly/releases) and install it in-game: **MODS > Import mod .zip**. Installed copies get update checks through the launcher automatically.

Source code and issues live in the [mods monorepo](https://github.com/shanehudson-gen1recomp-mods/gen1recomp-mods); this repo only hosts releases.
